## 💬 Résumé de notre expérience avec GitHub

Ce projet nous a permis de découvrir et de mettre en pratique les fonctionnalités de GitHub comme la création de branches, les pull requests, les merges, et la gestion collaborative de fichiers.  
Nous avons rencontré quelques petites difficultés au départ (notamment avec les droits des collaborateurs et la navigation dans les pull requests), mais cela nous a permis d’apprendre concrètement comment travailler en équipe de manière efficace.  
L'utilisation de GitHub nous a également aidés à mieux comprendre le versionnage de code et l’importance de la communication dans un projet collaboratif.
